# Shift Master（シフトマスター）- シフト申請・確定給与管理 PWA

アルバイトシフト希望申請、確定シフト管理、および22:00跨ぎ深夜割増給与の自動計算に対応した、完全オフライン動作可能な和モダンProgressive Web App (PWA) です。

---

## 📱 アプリの特徴・機能概要

1. **洗練された和モダンUI（Style 3: Minimalist & Clean, Material Design 3準拠）**
   - 藍鉄（深藍）と琥珀（ゴールド）、生成りの和紙をモチーフにした上品で落ち着いたデザイン。
   - スマホに最適化した月表示カレンダーGUIと、直感的な下部3タブ構成。

2. **希望シフト登録（メインカレンダー）**
   - **複数日一括仮登録**: トグルをONにして日付を複数タップ。「早番」「遅番」「ラスト」「休み」をワンタップで一括設定。
   - **定型テンプレート**: 1タップでシフト時間を入力可能。
   - **【重要制約の徹底】**: ユーザー要望に基づき、**希望シフト画面には給与額を表示しません**。
   - **FoodIT連携**: 店舗番号・社員番号から自動生成された `Param=店舗番号|社員番号` を使用し、シフト申請データをDirect POST送信、またはWeb申請ページへダイレクトアクセス。

3. **確定シフト & 給与自動計算**
   - **ワンタップ同期**: 「希望シフトからコピー」ボタンで、確定したシフトを一括反映。
   - **22:00跨ぎ給与自動分割計算**:
     - 通常時間帯（10:00〜22:00）：時給 1,300円
     - 深夜時間帯（22:00〜29:00 / 翌05:00）：時給 1,625円（25%深夜割増）
     - 22:00を跨ぐ勤務時間（例: 17:00〜23:30）を分単位で自動分割し、通常給与と深夜給与を正確に算出。
   - **リアルタイムサマリー**: 月間総労働時間、通常給与、深夜給与、合計概算額を常時リアルタイム表示。日別内訳リストも完備。

4. **設定画面**
   - 店舗番号（例: `02006`）と社員番号（例: `5155517`）を入力すると、認証キー `Param=02006|5155517` をリアルタイム自動生成。
   - 通常時給（デフォルト 1,300円）や定型シフト時間帯（早番・遅番・ラスト）のカスタマイズ対応。
   - 完全オフライン保存（端末内のローカルストレージ）＆ JSONバックアップ・復元機能。

5. **PWA & 完全オフライン対応**
   - `manifest.json` と Service Worker (`sw.js`) を完備。
   - 電波の届かない地下店舗や機内モードでもアプリが起動し、カレンダー操作や給与計算が動作します。

## 🚀 1. ローカルでの動作確認方法

### 方法 A: ブラウザで直接開く（最速）
`index.html` をダブルクリックするか、Google Chrome等のブラウザにドラッグ＆ドロップするだけで即座に動作します。

### 方法 B: ローカルHTTPサーバーで起動する（推奨: PWA検証用）
Service WorkerのキャッシュやPWA機能は `http://localhost` 上で完全に機能します。

#### Python を使う場合（インストール済み）:
プロジェクトフォルダ内で以下を実行：
```bash
python -m http.server 8080
```
ブラウザで `http://localhost:8080` を開きます。

#### 同じWi-Fi内のスマホから確認する場合:
PCのIPアドレス（例: `192.168.1.XX`）を調べ、スマホのChromeから `http://192.168.1.XX:8080` を開きます。

## 🌐 2. Vercel 等へ無料公開して Android スマホのホーム画面に追加する手順

完全無料でHTTPS（PWAのインストール要件）が使える **Vercel** または **Cloudflare Pages / GitHub Pages** への公開が最も簡単です。

### ステップ 1: Vercel へのデプロイ（ドラッグ＆ドロップ または Git）

#### ◆ 最も簡単な方法（Vercel CLI または Webダッシュボード）
1. [Vercel公式サイト](https://vercel.com) にアクセスして無料アカウントを作成（GitHubでログインがおすすめ）。
2. プロジェクトフォルダごとGitHubリポジトリにプッシュするか、Vercelダッシュボードの「Add New Project」からインポートします。
3. ビルドコマンドや設定は不要です（純粋なHTML/CSS/JS静的Webアプリのため、そのまま「Deploy」を押すだけ）。
4. 数秒で `https://shift-master-xxxx.vercel.app` のような無料HTTPS付きURLが発行されます！

*(※ GitHub Pages や Netlify、Cloudflare Pages にこのフォルダの中身をそのままアップロードしても1分で公開できます)*

---

### ステップ 2: Android スマホのホーム画面に追加（PWAインストール）

1. **Android スマホで Google Chrome を起動**します。
2. 上記でデプロイした URL（`https://shift-master-xxxx.vercel.app` 等）にアクセスします。
3. **インストール操作**:
   - 画面下部に「**ホーム画面に Shift Master を追加**」というバナーが表示されたら「追加」または「インストール」をタップします。
   - または、Chromeの右上メニュー（縦の3点リーダー「︙」）をタップし、「**アプリをインストール**」または「**ホーム画面に追加**」を選択します。
4. ホーム画面に「Shift Master」の和モダンアイコンが追加されます！

---

### ステップ 3: アプリとして使用する
- ホーム画面のアイコンをタップすると、ブラウザのアドレスバーが表示されない**ネイティブアプリ同様の全画面（スタンドアロン）**で起動します。
- 一度開けば、**機内モードや圏外（オフライン）でも即座に起動し、希望シフト入力や確定給与計算をいつでも快適に利用**できます。
